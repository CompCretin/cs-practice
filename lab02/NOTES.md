\# Git



Рабочая папка — это место, где находятся файлы проекта.



Индекс — это область, куда добавляются изменения перед коммитом.



Коммит — это сохранённая версия изменений в Git.



\## Git и GitHub



Git — это система контроля версий, которая хранит историю изменений проекта.



GitHub — это сервис для хранения Git-репозиториев и совместной работы с ними.



\## Использованные команды



`git status` — показывает состояние рабочего каталога и индекса.



`git diff` — показывает изменения, которые ещё не добавлены в индекс.



`git diff --staged` — показывает изменения, добавленные в индекс и готовые к коммиту.

## Ветки

Ветка — это отдельная линия разработки в Git.

Если сделать новый коммит, находясь в ветке, эта ветка переместится на новый коммит.

Слияние объединяет изменения из одной ветки с другой.
