\# Git



Рабочая папка — это место, где находятся файлы проекта.



Индекс — это область, куда добавляются изменения перед коммитом.



Коммит — это сохранённая версия изменений в Git.



\## Git и GitHub



Git — это система контроля версий, которая хранит историю изменений проекта.



GitHub — это сервис для хранения Git-репозиториев и совместной работы с ними.
